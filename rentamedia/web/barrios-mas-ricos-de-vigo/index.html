Preguntas frecuentes

¿Cuál es el barrio más rico de Vigo?

Según la Agencia Tributaria, en 2024 el código postal con más renta de Vigo fue el 36390 (Oya), con una renta bruta media de 51.503 € por declaración, 1,5 veces la media de España.

¿Cuál es el barrio más pobre de Vigo?

El código postal con menos renta fue el 36207 (Teis), con 26.838 € brutos por declaración: 1,9 veces menos que Oya.
