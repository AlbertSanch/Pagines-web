    Sobre Otoño

    El otoño astronómico empieza con el equinoccio de septiembre, entre el 22 y el 23 de septiembre, cuando el día y la noche duran casi lo mismo. Termina con el solsticio de diciembre, cuando empieza el invierno.

    A finales de octubre llega el cambio de hora al horario de invierno, y anochece una hora antes.
