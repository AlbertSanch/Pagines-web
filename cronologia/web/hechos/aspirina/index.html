¿Cuándo se inventó la aspirina?

💊

1897

Se sintetiza la aspirina

Felix Hoffmann, químico de Bayer, sintetizó en 1897 el ácido acetilsalicílico en una forma estable. Se vendió con el nombre de Aspirina a partir de 1899.
