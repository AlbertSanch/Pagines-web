¿En qué año se construyó el Empire State?

🏙️

1931

Se inaugura el Empire State Building

El Empire State Building de Nueva York se inauguró en 1931, tras solo unos 13 meses de obras, y fue el edificio más alto del mundo durante cuatro décadas.
