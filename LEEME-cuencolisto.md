# CuencoListo — siguientes pasos

Web estática de comparativas de comederos automáticos y fuentes para mascotas.

## 1. Dominio
El nombre elegido es **CuencoListo**. Comprueba en Namecheap si `cuencolisto.com` está libre y cómpralo.
Si no está disponible y eliges otro dominio, avisa a Claude para cambiar `cuencolisto.com` en todos los archivos.

## 2. Publicar en Netlify
1. En Netlify: **Add new project → Deploy manually** y arrastra la carpeta `cuencolisto-site`.
2. **Domain management → Add a domain** → `cuencolisto.com`.
3. Copia los 4 nameservers y pégalos en Namecheap (**Domain List → Manage → Nameservers → Custom DNS**).
4. Espera a que aparezca "HTTPS enabled".

## 3. Amazon Afiliados
- Usa tu misma cuenta. En **Configuración de la cuenta → Editar la lista de sitios web**, añade `https://cuencolisto.com`.
- Recomendado: en **Administrar IDs de seguimiento** crea un ID nuevo (p. ej. `cuencolisto-21`) para saber qué ventas vienen de esta web, y pide a Claude que lo cambie en los enlaces (ahora usan `albert671-21`).

## 4. Google Search Console
Añade `cuencolisto.com` como propiedad de tipo Dominio, verifica con el registro TXT en Netlify y envía `sitemap.xml`.
